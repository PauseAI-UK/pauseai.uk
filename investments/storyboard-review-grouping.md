# Group the storyboard's changed frames

Size: M. Kind: tools.

## Problem

A full review has about 1,000 screenshots. A change to the header or a UI kit piece changes hundreds of frames, and the report shows each one separately.

## Fix

Group changed frames by where and how much they changed, so the same change across 300 frames is one item to look at. Add a test that keeps flows to about ten frames, as AGENTS.md asks.

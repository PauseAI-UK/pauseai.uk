# The copy waiting for approval

Size: S. Kind: tools.

## Problem

Francis approves each ⁂ placeholder before it becomes real copy, so for each PR he asks what copy there is and where it shows. Agents answer by grepping and describing, and he then finds each piece on the page.

## Fix

`npm run copy` lists the placeholders the branch adds or changes, each with its text, the file and key it's in, and the storyboard frames that show it, read from the latest run. Approved copy is then edited in one place, with the ⁂ removed.
